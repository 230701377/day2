CONTRACT LIFECYCLE & APPROVAL MANAGEMENT SYSTEM - QUICK START
==============================================================

This file mirrors the README but is condensed for fast reference.

PREREQUISITES
-------------
- Docker Desktop (for the recommended one-command setup)
  OR
- Python 3.11+, Node 20+, PostgreSQL 16 with pgvector, Redis 7

ONE-COMMAND SETUP (Docker)
--------------------------
$ cp .env.example backend/.env
$ docker compose up --build
- Frontend: http://localhost:3000
- API:      http://localhost:8000/api/v1/docs
- MinIO:    http://localhost:9001 (minio/minio123) - if enabled

LOCAL SETUP (no Docker)
-----------------------
1. Backend
   $ cd backend
   $ python -m venv .venv && source .venv/bin/activate
   $ pip install -r requirements.txt
   $ cp .env.example .env
   $ createdb contracts
   $ psql contracts -c "CREATE EXTENSION vector;"
   $ alembic upgrade head
   $ python scripts/seed.py
   $ uvicorn app.main:app --reload --port 8000

2. Frontend
   $ cd frontend
   $ cp .env.example .env.local
   $ npm install
   $ npm run dev

TROUBLESHOOTING
---------------
- Port 5432 in use?  edit docker-compose.yml postgres.ports
- LLM features disabled?  set LLM_PROVIDER=openai and LLM_API_KEY in .env
- Reset state?  docker compose down -v && docker compose up --build
